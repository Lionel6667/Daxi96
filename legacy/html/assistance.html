Commander un Taxi

Comment passer une commande ?

Pour commander un taxi sur DAXI, suivez ces étapes simples :

  • 1. Connectez-vous à votre compte ou créez-en un nouveau
  • 2. Remplissez le formulaire avec :
    • Point de départ (localisation actuelle)
    • Nombre de passagers
    • Destination finale
    • Date et heure souhaitées
  • 3. Ajoutez une description (optionnel mais recommandé)
  • 4. Cliquez sur "Commander" et attendez la confirmation

Vous recevrez une notification dès qu'un Prix a été proposé à votre course.

Quel est le rôle de la description dans ma commande ?

La description est très importante ! Elle permet de :

  • Faciliter votre identification : "Je porte un t-shirt rouge", "Je suis devant la pharmacie"
  • Préciser des détails : "Grand bâtiment bleu", "3ème maison après le carrefour"
  • Indiquer des besoins spéciaux : "J'ai beaucoup de bagages", "Je voyage avec un enfant"
  • Ajouter des instructions : "Sonnez en arrivant", "Appelez-moi 5 min avant"

Plus votre description est précise, plus le chauffeur vous trouvera facilement !

Puis-je annuler ma commande ?

Oui ! Vous pouvez gérer vos commandes :

  • Avant acceptation : Annulation gratuite en cliquant sur le bouton "Annuler"
  • Après acceptation : Contactez le chauffeur ou le adm via le chat box present ou dans les informations de votre commande pour modification
  • Annulation tardive : Des frais peuvent s'appliquer si le chauffeur est déjà en route

Mon Compte

À quoi sert l'ID de mon compte ?

Votre ID de compte (exemple: #7687) est un numéro unique qui permet de :

  • Vous identifier rapidement auprès du support client
  • Suivre vos commandes dans notre système
  • Résoudre des problèmes : communiquez votre ID pour une assistance plus rapide
  • Faciliter la connexionvous connecter sur le site plus rapidement

Vous pouvez trouver votre ID en haut à droite de la page, à côté de votre nom.

J'ai oublié mon mot de passe, que faire ?

Pas de panique ! Suivez ces étapes :

  • Cliquez sur "Connexion"
  • Sélectionnez "Mot de passe oublié ?"
  • Entrez votre email ou numéro de téléphone
  • Vous recevrez un code de réinitialisation
  • Créez votre nouveau mot de passe

Si vous ne recevez pas le code, vérifiez vos spams ou contactez notre assistance.

Paiements & Tarifs

Quels sont les modes de paiement acceptés ?

DAXI accepte paiement :

  • En Espèces : Payez directement au chauffeur
Comment sont calculés les tarifs ?

Nos tarifs sont basés sur :

  • Distance : Kilométrage entre le point A et B
  • Durée : Temps estimé du trajet
  • Horaire : Tarifs majorés la nuit (22h-6h) et jours fériés
  • Type de véhicule : Standard, Confort, VIP
  • Demandes spéciales : Bagages encombrants, arrêts multiples

Un devis est affiché AVANT validation de votre commande.

Sécurité

Comment vérifier l'identité de mon chauffeur ?

Votre sécurité est notre priorité ! Vérifiez toujours :

  • Photo du chauffeur : Visible dans l'app après acceptation
  • Nom complet : Doit correspondre à la notification
  • Note et avis : Consultez les évaluations d'autres clients
  • Badge de vérification : Tous nos chauffeurs sont certifiés

En cas de doute, contactez immédiatement notre support !

Support Technique

L'application ne fonctionne pas correctement

Essayez ces solutions rapides :

  • Fermez et rouvrez l'app
  • Vérifiez votre connexion internet
  • Attendez un petit moment : Il se peut qu'une mise à jour soit en train d'être déployée
  • Redémarrez votre téléphone

Si le problème persiste, contactez notre chatbot ou le support technique.
